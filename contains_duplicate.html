Statement

Write a function that determines whether a list of integers contains any duplicates.
The function should return True if any value appears at least twice in the list and False if every element is distinct.

Solution

We can solve this problem efficiently using a set.
As we iterate through the list, we keep track of all numbers we've seen so far.
- If we encounter a number that’s already in the set, it means there’s a duplicate, so we return True.
- Otherwise, we add the number to the set and continue.
If the loop finishes without finding any duplicates, we return False.

This approach runs in O(n) time because each lookup and insertion in a set takes constant time on average.
